# Правила проекта Elementa

- Общайся с пользователем и пиши комментарии к коду на русском языке.
- В конструкторах классов, включая `data class`, каждый параметр размещай на отдельной строке. Используй завершающую запятую, даже если параметр один:

```kotlin
data class AuthUser(
    val id: String,
    val username: String,
)
```

- Соблюдай Clean Architecture и MVI: доменные модели и сценарии не зависят от Android и сетевых библиотек; транспорт, хранение, преобразование данных и представление имеют отдельные обязанности.
- Самостоятельные модели, контракты, реализации репозиториев и источники данных размещай в отдельных файлах.
- Сообщения коммитов пиши на русском языке с префиксом `[ELEMENTA-XXX]`, сохраняя принятую нумерацию проекта.
