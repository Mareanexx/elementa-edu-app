**Elementa** — это Android-приложение для изучения химии с встроенным адаптивным ридером электронных книг в формате EPUB. Приложение предоставляет доступ к специализированной научной и учебной литературе, позволяет делать заметки и выделения прямо в тексте, отслеживать прогресс чтения и проходить интерактивные тесты для закрепления материала.

## Установка и сборка

1. Клонируйте репозиторий:

    ```bash
    git clone https://github.com/Mareanexx/elementa-edu-app.git
    ```

2. Откройте проект в **Android Studio**  
   (рекомендуемая версия — *Android Studio 2025.2.1* или выше)

3. Убедитесь, что установлены:
    - Gradle: **8.13**
    - Android Gradle Plugin: **8.13.2**

4. Синхронизируйте проект с Gradle и выполните сборку.

5. Запустите приложение на устройстве или эмуляторе с **Android 8.0 (API 26)** или выше.
