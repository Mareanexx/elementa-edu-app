# Чтение, скачивание и заметки

## Формат публикации

Сервер отдаёт **EPUB 3 с изменяемой вёрсткой** (`application/epub+zip`). Текст — XHTML, формулы — Presentation MathML, индексы — `sub`/`sup`. Иллюстрации хранятся внутри EPUB в PNG, JPEG, WebP или GIF. Текущая версия ридера использует собственную типографику и не исполняет скрипты, стили и внешние ресурсы издателя. PDF, фиксированная вёрстка, SVG и DRM в этот контракт не входят.

Максимальный архив — 100 МиБ, до 500 глав, 5 млн символов текста. Распаковка ограничена 150 МБ, один ресурс — 12 МБ. Сервер должен заранее проверять EPUB, отдавать стабильную версию и контрольную сумму. Демонстрационный транспорт создаёт настоящий EPUB с авторским учебным текстом; он не воспроизводит издания с обложек каталога.

## Подготовка книги

`GET /api/v1/books/{book_id}/reading-manifest` — с bearer-авторизацией:

```json
{
  "book": {
    "id": "book_1",
    "title": "Органическая химия",
    "authors": "Автор",
    "pages": 160,
    "pages_read": 48,
    "cover_url": null,
    "cover_key": "chemistry",
    "rating_average": 4.4,
    "rating_count": 98,
    "tags": [{"id":"organic","label":"Органическая химия","kind":"topic"}],
    "favorite": false,
    "want_to_read": true,
    "collection_count": 1
  },
  "format": "application/epub+zip",
  "version": "edition-2026-v1",
  "content_path": "/api/v1/reading-content/book_1/book.epub?ticket=limited-download-token",
  "byte_size": 3400000,
  "sha256": "64 строчных шестнадцатеричных символа"
}
```

`content_path` — ограниченная ссылка того же HTTPS-origin, с префиксом `/api/v1/`. Для файла применяется отдельный клиент без bearer-токена и без HTTP-перенаправлений. Ссылка должна работать без cookie и иметь достаточное время жизни для загрузки. Повторное получение манифеста обновляет истёкшую ссылку.

Файловая ручка возвращает `200`, точные байты EPUB и `Content-Length`. Для возобновления поддерживает `Range: bytes=N-` и `206` с точным `Content-Range: bytes N-(size-1)/size`. Допустимо ответить `200` и передать файл заново. Клиент проверяет размер и SHA-256, распаковывает в промежуточный каталог, затем атомарно помечает публикацию готовой. Частичный архив никогда не открывается.

Каждая попытка скачивания имеет собственный идентификатор и промежуточный каталог: отменённая задача не меняет состояние повторной загрузки.

Явная кнопка скачивания закрепляет файл и добавляет его в локальный раздел «Скачано». Загрузка продолжается через WorkManager в фоне; прогресс и отмена доступны в уведомлении. Отказ в разрешении на уведомления не мешает скачиванию. Уведомление о завершении открывает книгу только в аккаунте, который её скачал. Выход из аккаунта останавливает его фоновые задачи.

Обычное открытие сначала готовит весь документ в локальный кеш. Скачанный файл открывается без запроса манифеста. Незакреплённый кеш ограничен тремя книгами и 160 МБ; открытая книга не удаляется. Удаление скачанного файла сохраняет позицию и заметки. Для замены сохранённого издания пользователь может удалить файл и скачать актуальную версию.

## Позиция чтения

`GET /api/v1/users/me/reading/books/{book_id}/progress` возвращает позицию или `404`, если её ещё нет.

`PUT /api/v1/users/me/reading/books/{book_id}/progress`:

```json
{
  "device_id": "uuid-installation",
  "client_revision": 12,
  "position": {
    "book_id": "book_1",
    "version": "edition-2026-v1",
    "chapter_id": "chapter_2",
    "offset": 14520,
    "progression": 0.3,
    "source_pages_read": 48,
    "updated_at": 1792348800000
  }
}
```

Ответ `200` — объект `position`. Сервер идентифицирует пользователя по токену, проверяет доступ к книге и диапазоны, принимает повтор одной ревизии идемпотентно. Для нескольких устройств выбирает актуальную позицию по `updated_at` и ведёт ревизии отдельно для каждого `device_id`.

`offset` — глобальная позиция в UTF-16 внутри текстовых узлов нормализованной публикации. Текущая версия нормализатора — `reader-html-v1`: главы по порядку spine, идентификаторы `chapter_1`, `chapter_2` и т. д.; XHTML очищается `EpubProcessor`, затем ридер индексирует `#content.textContent`. Сервер хранит якорь как непрозрачные данные клиента. При изменении нормализатора нужна миграция якорей/новая версия протокола. Идентичный EPUB с другой типографикой даёт те же текстовые адреса.

`progression` — 0…1. `source_pages_read` связывает прогресс с числом страниц издания в библиотеке. Счётчик в ридере показывает экранные страницы, поэтому меняется при изменении шрифта и полей. При отсутствии локального якоря первая позиция вычисляется по серверному прогрессу. При смене версии издания старый числовой offset не используется.

Достижение последней страницы само по себе не отмечает книгу прочитанной. Ридер предлагает подтвердить завершение и до подтверждения сохраняет `progression < 1` и `source_pages_read < book.pages`. После действия «Отметить прочитанной» тот же PUT сохраняет `progression = 1` и `source_pages_read = book.pages`; книга остаётся открытой. При повторном просмотре предыдущих глав якорь и `progression` меняются, а `source_pages_read` остаётся равным общему числу страниц: статус «Прочитано» сохраняется. Сброс статуса выполняется отдельным действием в библиотеке.

Позиция сохраняется в Room с коротким debounce, при уходе в фон и перед закрытием крестиком. Сетевые обновления отправляются реже и не блокируют чтение. Локальная несинхронизированная позиция имеет приоритет над пришедшей с сервера.

## Выделения и заметки

- `GET /api/v1/users/me/reading/books/{book_id}/annotations?limit=100&cursor=…` → `{ "items": [...], "next_cursor": null }`.
- `PUT /api/v1/users/me/reading/books/{book_id}/annotations/{annotation_id}` → сохранённый объект. UUID создаёт клиент; повтор запроса не создаёт копию.
- `DELETE /api/v1/users/me/reading/books/{book_id}/annotations/{annotation_id}` → `204`. Повторный `404` также считается успехом.

```json
{
  "id": "uuid-annotation",
  "book_id": "book_1",
  "anchor": {
    "version": "edition-2026-v1",
    "chapter_id": "chapter_2",
    "start": 14520,
    "end": 14524,
    "quote": "Атом",
    "prefix": "До 64 символов перед цитатой",
    "suffix": "До 64 символов после цитаты"
  },
  "color": "mint",
  "note": "Проверить определение",
  "created_at": 1792348800000,
  "updated_at": 1792348800000,
  "revision": 1,
  "deleted": false
}
```

Цвета: `amber`, `mint`, `sky`, `lavender`, `rose`, `peach`. Максимум 10 000 UTF-16 символов в цитате и 4 000 в заметке; `end - start` должен совпадать с длиной `quote`. Время — Unix milliseconds UTC. `note: null` означает обычное выделение. Удалённые объекты возвращаются как tombstone (`deleted: true`) для синхронизации других устройств.

Сначала изменения атомарно сохраняются локально, затем отправляются через постоянную очередь WorkManager. Подтверждение сервера помечает только отправленную локальную ревизию; правка, сделанная во время запроса, остаётся в очереди. Серверная версия не заменяет несинхронизированную локальную. Автоматическая повторная отправка, периодическая проверка и запуск приложения восстанавливают очередь после остановки процесса. Курсор не должен повторяться.

Выделения другой версии публикации остаются в списке заметок, но не рисуются поверх нового текста и не переводят к неверной цитате.

## Настройки и ошибки

Тема, шрифт, размер, интервал, поля, выравнивание, формулы, счётчик страниц и удержание экрана сохраняются локально для аккаунта. Настройки не вызывают сетевую перезагрузку публикации. Открытый экран удерживает собственную ссылку на локальный файл, чтобы очистка кеша и пересоздание Activity не удалили читаемую книгу. Изменения полок и статуса чтения обновляют также локальный снимок скачанной книги. Ридер показывает весь подготовленный текст в закрытом HTTPS WebViewAssetLoader-origin; произвольные сетевые и файловые запросы запрещены.

Серверные ошибки: `401` — сессия, `403` — права, `404` — книга/прогресс, `429` — ограничение частоты, `5xx` — временный сбой. Сетевые сбои и таймауты повторяются с backoff. Повреждённый файл, неподдерживаемый формат, недостаток места и некорректный ответ показываются отдельно. При отсутствии сети скачанные книги, настройки, выделения и заметки продолжают работать.

Демо-настройки для QA: preferences `reader_mock_controls`, `delay_ms` и `download_delay_ms` (Long), `next_status` (Int), `corrupt` (Boolean). Все демо-данные разделены по аккаунтам.
